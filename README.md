# Gõ Phím Tí Hon

Ứng dụng web giúp trẻ em học gõ bàn phím 10 ngón thông qua bài học và trò chơi.

## Tính năng

- **Bàn phím tô màu theo ngón tay** và hình hai bàn tay sáng lên đúng ngón cần dùng.
- **18 bài học** đi từ hàng phím giữa (F, J có gờ nổi), lên hàng trên, xuống hàng dưới, xen kẽ các bài ôn tập. Mỗi bài có tối đa 3 sao theo độ chính xác; xong bài trước mới mở bài sau.
- **Bắn bóng bay**: gõ đúng chữ trên bóng để bắn vỡ. Màu bóng là màu ngón tay cần dùng.
- **Đua với bạn**: gõ đủ 10 từ để chú thỏ về đích trước ốc sên, rùa hoặc cáo.
- Cảnh báo khi Unikey / bộ gõ tiếng Việt hoặc Caps Lock đang bật.
- Tiến độ và kỷ lục được lưu trong trình duyệt (localStorage).

## Chạy thử

Không cần cài đặt hay build. Mở trực tiếp file `index.html` bằng trình duyệt trên máy tính có bàn phím.

Có thể bật **GitHub Pages** (Settings → Pages → Deploy from branch `main`, thư mục `/root`) để chơi qua đường link.
